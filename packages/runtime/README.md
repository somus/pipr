# @usepipr/runtime

`@usepipr/runtime` powers Pipr's CLI and code-host integrations. It isn't a public authoring API, and direct imports aren't supported.

Use [`@usepipr/cli`](https://www.npmjs.com/package/@usepipr/cli) to run Pipr. Repository configs should import from [`@usepipr/sdk`](https://www.npmjs.com/package/@usepipr/sdk).

For user-facing behavior, see:

- [Runtime flow](https://pipr.run/docs/concepts/runtime)
- [Comments and findings](https://pipr.run/docs/concepts/comments)
- [Trust and security](https://pipr.run/docs/concepts/trust-security)
